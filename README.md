# FoodSafe - Professional Cold Storage Management System

A comprehensive Next.js solution for high-efficiency cold storage operations, built with ShadCN UI, Tailwind CSS, and Firebase.

## 🚀 Key Features

### 1. Inward & Outward Registers
- **Inward Register (Chamberwise):** Detailed tracking of incoming stock with Inward Numbers, Brand, Batch, and specific Chamber/Block/Zone placement.
- **Outward Register:** Professional release tracking referencing original inward entries to maintain perfect stock reconciliation.
- **Stock Reports:** Real-time balance calculations for both quantity and weight.

### 2. Statutory & Official Documents
- **Goods Receipt Notes (GRN):** Official receipts generated upon stock entry.
- **Delivery Orders (DO):** Printable release orders for drivers and security.
- **Professional PDF Export:** All registers and documents are formatted for professional landscape/portrait printing.

### 3. Client & Billing Management
- **Statutory Details:** Integrated GSTIN and PAN card tracking.
- **Banking Integration:** Full bank account and IFSC details for automated invoicing.
- **Billing Cycles:** Support for 15-day and 30-day billing periods.
- **Professional Invoices:** Automated GST calculations including Varai and L/UL charges.

### 4. AI-Powered Optimization
- **Chamber Optimizer:** Uses Google Gemini AI (via Genkit) to suggest optimal item placement based on expiry dates, turnover rates, and chamber temperatures.

### 5. Operational Insights
- **Itemwise/Locationwise Reports:** Aggregated stock views.
- **Audit Logs:** Tracking user logins and software operations for security.
- **Automated Reconciliations:** Real-time "Opening vs Issues vs Closing" logic.

## 🛠 Tech Stack
- **Framework:** Next.js 15 (App Router)
- **UI:** React, Lucide Icons, ShadCN UI, Tailwind CSS
- **AI:** Genkit with Gemini 2.5 Flash
- **Database/Auth:** Integrated Firebase (Production Ready)
